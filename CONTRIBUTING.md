# Contributing

DAVID AI Labs welcomes thoughtful contributions to its public engineering projects.

## Standards

- Open issues before proposing major architectural changes.
- Include tests when modifying executable code.
- Document assumptions and limitations.
- Do not submit credentials, private data, or client-owned code.
- Do not publish client information without written authorization.
- Respect the license and contribution rules of each repository.

## Pull Requests

Pull requests should explain the problem, implementation, validation, and relevant tradeoffs.
